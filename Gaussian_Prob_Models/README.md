# Gaussian Discriminant Analysis — LDA / QDA from Scratch

Linear and Quadratic Discriminant Analysis built from scratch with NumPy and SciPy. Each class is modeled as a multivariate Gaussian; classification is fully probabilistic — posterior class probabilities come from Bayes' rule with Gaussian log-likelihoods computed in log space, with no point-estimate shortcuts and no machine-learning frameworks.

## The Model

Each class $c$ is modeled as a multivariate Gaussian with mean $\mu_c$, covariance $\Sigma_c$, and prior $\pi_c$ (class frequency).

- **Priors:** $\pi_c = N_c / N$
- **Means:** $\mu_c = \frac{1}{N_c}\sum_{i:\,y_i=c} x_i$
- **QDA covariances:** one MLE covariance per class, $\Sigma_c = \text{cov}(X_c)$
- **LDA covariances:** a single pooled covariance shared by all classes, $\Sigma = \frac{1}{N-K}\sum_c\sum_{i:\,y_i=c}(x_i-\mu_c)(x_i-\mu_c)^\top$ (so `LDA` subclasses `QDA` and only overrides `fit`)
- **Log-likelihood:** via the Mahalanobis distance and `slogdet`,
$$\log P(x \mid c) = -\tfrac{1}{2}\left(D\log 2\pi + \log\lvert\Sigma_c\rvert + (x-\mu_c)^\top\Sigma_c^{-1}(x-\mu_c)\right)$$
- **Posterior:** $P(c \mid x) \propto \pi_c \cdot P(x \mid c)$, joint log-probabilities normalized with `scipy.special.logsumexp` (`predict_proba`/`predict_log_proba`); `predict` takes the argmax

### Why QDA vs LDA?

QDA fits a separate covariance per class, so its decision boundary is quadratic — it wins when classes spread differently (`unequal_cov`). LDA shares one pooled covariance, so its boundary is linear — it matches QDA when classes share the same spread (`equal_cov`) while estimating fewer parameters.

## Getting Started

Requires Python ≥ 3.12. Use the project virtualenv (system `python3` lacks SciPy).

```bash
cd Gaussian_Prob_Models
PYTHONPATH=src python -m gaussian_prob_models
```

One run trains LDA and QDA on all four dataset profiles, prints accuracy / macro-precision / macro-recall / macro-F1 plus per-class scores, saves every figure and `metrics.json` to `reports/`, and opens each figure on screen. Flags:

```bash
PYTHONPATH=src python -m gaussian_prob_models --no-show --output-dir my_reports
```

### Tests (manual)

Tests never run as part of the pipeline; run them explicitly:

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

### Data generator alone

```bash
python data/generate_data.py
```

Profiles: `unequal_cov` (QDA showcase), `equal_cov` (LDA showcase), `multiclass` (3 classes), `high_dim` (stability stress test).

### As a library

```python
from gaussian_prob_models import LDA, QDA, generate_synthetic_classification_data

X, y = generate_synthetic_classification_data(dataset_type="unequal_cov")

model = QDA()
model.fit(X, y)
pred = model.predict(X)            # class labels
proba = model.predict_proba(X)     # posterior probabilities, rows sum to 1
```

## Results — Synthetic Benchmark (600 samples/profile, 70/30 split, seed 42)

| Profile | Model | Accuracy | Macro-P | Macro-R | Macro-F1 |
| --- | --- | --- | --- | --- | --- |
| unequal_cov | LDA | 98.33% | 98.38% | 98.25% | 98.31% |
| unequal_cov | **QDA** | **99.44%** | 99.50% | 99.38% | 99.44% |
| equal_cov | **LDA** | **99.44%** | 99.50% | 99.38% | 99.44% |
| equal_cov | QDA | 98.89% | 99.02% | 98.75% | 98.87% |
| multiclass | **LDA** | **97.22%** | 97.57% | 97.14% | 97.29% |
| multiclass | QDA | 96.67% | 96.91% | 96.67% | 96.76% |
| high_dim (5-D) | LDA | 89.44% | 89.46% | 89.48% | 89.44% |
| high_dim (5-D) | **QDA** | **90.00%** | 90.04% | 90.04% | 90.00% |

As theory predicts: QDA wins on `unequal_cov`, LDA matches it on `equal_cov`, both handle 3 classes, and both stay numerically stable in higher dimensions.

## Implementation Philosophy

- **From scratch** — no scikit-learn, PyTorch, or TensorFlow; pure NumPy/SciPy
- **Generative + probabilistic** — full Gaussian class-conditionals with exact Bayes posteriors, no discriminative shortcuts
- **Numerical stability** — log-space scoring via `slogdet`/`logsumexp`; Mahalanobis form avoids raw determinants
- **Single source of truth** — one data generator (`datasets.py`) feeds the pipeline, the CLI shim, and the tests
- **Separation of concerns** — tests run manually and never as a pipeline side effect
